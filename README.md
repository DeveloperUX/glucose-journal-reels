# glucose-journal-reels

Finished Glucose Journal reels, ready to post. Each reel has three files in `reels/`:

- `<name>.mp4`: the full reel with voice, music and sound effects (1080x1920, 30 fps)
- `<name>-silent.mp4`: the same video with no audio, for adding a trending sound in the app
- `<name>-cover.png`: the cover frame

Every file is under 20 MB so it can be served through jsDelivr for Instagram uploads.
All reels are education only, not medical advice.

| Reel | Length | Style | Topic |
| --- | --- | --- | --- |
| `cell-city` | 33 s | Cartoon city inside a cell | Insulin, muscle vs fat |
| `stone-channels` | 38 s | Carved stone relief map | Where glucose flows: muscle or fat |
| `piggy-banks` | 34 s | Pop-art piggy banks | Gain muscle not fat, lose fat not muscle |
| `microscope` | 41 s | Fluorescence microscopy documentary | GLUT4, glycogen, mTOR, lipase |
| `doodle` | 27 s | Cozy app-style cartoon for teens | Insulin is a key, the gym opens extra doors |

Source code for every reel lives in [DeveloperUX/ai-videos](https://github.com/DeveloperUX/ai-videos) under `reels/src/videos/<name>`.
